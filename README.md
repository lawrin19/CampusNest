campusNest Sierra Leone

Student Accommodation Website

1. Introduction

CampusNest Sierra Leone is a student accommodation website designed to help students find affordable, comfortable and suitable housing near their educational institutions. The website connects students with room listings, apartments and potential roommates, making the accommodation search more organised and convenient.

Finding suitable accommodation can be challenging for students, especially those relocating for education. Students often consider rent, location, safety, facilities and roommate compatibility before making a decision.

CampusNest aims to simplify this process through a user-friendly and visually appealing website that brings relevant accommodation information together.

2. Project Proposal

The aim of this project is to design and develop a responsive multi-page website that helps students in Sierra Leone explore accommodation options and discover potential roommates.

The website provides the following features:

* Home: Introduces CampusNest and directs users to the main services.
* About: Explains the purpose and vision of CampusNest.
* Find a Room: Presents accommodation listings with photographs, prices, locations and facilities.
* Roommates: Displays roommate profiles, interests, hobbies and lifestyle preferences.
* Contact: Provides information for enquiries and support.
* List a Room: Provides an accommodation listing interface for property owners, where implemented.

The project focuses on creating an attractive, accessible and easy-to-navigate website using HTML and CSS.

3. Target Users

CampusNest is designed primarily for university and college students in Sierra Leone.

The target users include:

* Students looking for affordable accommodation near campus.
* Students relocating from other towns or communities.
* Students who prefer sharing accommodation with roommates.
* Students who prefer private rooms or apartments.
* Landlords and property owners offering student accommodation.

The website aims to support different budgets, preferences and accommodation needs.

4. User Research

User research helps identify students’ accommodation challenges, expectations and preferences. It can guide the website’s design and help ensure that its features respond to real user needs.

The proposed research methods include questionnaires, interviews, competitor reviews and usability testing.

Research questions include:

* How do students currently find accommodation?
* What is their preferred monthly rental budget?
* Which locations and facilities are most important?
* Would they prefer living alone or sharing with roommates?
* What qualities do they look for in a roommate?
* What safety concerns do they have when searching for accommodation?

The research will help inform decisions about accommodation listings, search options, roommate profiles and website navigation.

The proposed findings will need to be supported by actual research responses. Research results and feedback should be added after data collection.

5. User Journey

The user journey describes how a student may interact with CampusNest.

1. Discover: The student visits the website and learns about its services.
2. Explore: The student chooses to find a room or discover roommates.
3. Search: The student browses available options and relevant information.
4. Compare: The student considers prices, locations, facilities and personal preferences.
5. Enquire: The student contacts the relevant person for more information.
6. Decide: The student evaluates the available information before making an accommodation decision.

This journey aims to make the accommodation discovery process simple, clear and convenient.

6. Design and Development

CampusNest is developed using HTML5 and CSS3, with Visual Studio Code as the development environment and GitHub for project hosting.

The website follows the original wireframe layout while introducing colour, photographs, branding and improved visual presentation.

The design uses purple, blue, white, light lavender and dark navy to maintain a consistent visual identity. Property cards, roommate profiles, clear headings and organised content help users navigate the website.

Responsive web design is an important part of the project. The website is intended to adapt to mobile phones, tablets and desktop computers using flexible layouts, CSS Grid, Flexbox and media queries.

The website should be tested across different screen sizes to check navigation, image scaling, readability, accessibility and layout consistency.

The project also considers semantic HTML, maintainable CSS, appropriate image use and clear navigation.

7. Conclusion

CampusNest Sierra Leone aims to improve the student accommodation search experience by bringing housing information and roommate discovery together in one convenient platform.

Through responsive design, organised content and a user-centred approach, the project seeks to help students explore accommodation options and make more informed decisions.

The development of CampusNest demonstrates the application of web design principles, including layout planning, visual hierarchy, responsive development and user experience design.

Future improvements may include advanced search filters, verified property listings, account registration, messaging and online booking, depending on future development requirements.
